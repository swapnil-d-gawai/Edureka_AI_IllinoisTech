## LMS demonstration walkthrough

- **Resources:** <https://lms.snvaveranda.com/mod/resource/view.php?id=8609> and <https://lms.snvaveranda.com/mod/resource/view.php?id=15704>.
- **Actual assignment:** resource 8609 demonstrates Python numbers and arithmetic/operators. Resource 15704 is a companion script bundle with a review-classification warm-up, model-metadata type inventory, operator-based LLM-cost calculation, and an interactive mini assistant.
- **Input/data shape:** the number activity is small scalar values; the scripts use lists of short review strings, model-configuration key/value records, token counts, prices, and terminal text input. No course dataset is required.
- **Beginner workflow:** (1) predict the numeric result, (2) run one expression at a time, (3) inspect `type(value)`, (4) classify list/dict/string/set roles, (5) trace operator precedence, (6) enter one synthetic review into the mini-assistant pattern.
- **Relationship to current examples:** `demo-operators.py` and `demo-data_types.py` are close, original study companions. `course_workspace_planner.py` is an **original extension beyond the LMS demonstration**: it turns the same types/operators into validated JSON and filesystem planning.
- **Deliberate practice:** write the input and expected type/output before running; replace one integer with a float, then a Boolean; invent two review records and explain every condition; finish by explaining why the result is or is not correct without relying only on output.

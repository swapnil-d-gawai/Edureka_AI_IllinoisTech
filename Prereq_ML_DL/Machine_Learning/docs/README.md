## Course map

1. **Problem framing:** business objective, unit of prediction, target, and
   action.
2. **Data and splits:** supervised versus unsupervised learning, features,
   label provenance, leakage prevention, and evaluation partitions.
3. **Preparation:** missing values, scaling, encoding, and feature consistency.
4. **Models:** linear and logistic baselines, trees, ensembles, and clustering.
5. **Evaluation:** loss and metrics, imbalance, thresholds, validation, and
   cross-validation.
6. **Production:** hyperparameter search, reproducible experiments, deployment,
   drift monitoring, and responsible-model checks.

## Study sequence

Read [NOTES.md](NOTES.md) before the recordings for vocabulary, then watch the
eight videos in order. After videos III–V, run the
[offline churn example](../examples/churn_pipeline.py). Revisit the evaluation
and responsible-ML sections after the example, predict its behavior without
looking at the output, and then verify the result. Finish by writing a
one-paragraph model card describing intended use, data, primary metric,
threshold, known limitations, and monitoring plan.

See [the example guide](../examples/README.md) for execution instructions.

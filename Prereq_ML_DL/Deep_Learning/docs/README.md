## Course map

1. **Representations:** tensors, shapes, units, and tensor operations.
2. **Network mechanics:** perceptrons, multilayer networks, activations, loss,
   gradients, and backpropagation.
3. **Learning process:** initialization, SGD/Adam, batches, epochs, and
   regularization.
4. **Architectures:** CNNs, recurrent/sequence models, and transformer
   foundations.
5. **Engineering:** the PyTorch-style loop, evaluation, common failure modes,
   checkpointing, early stopping, and inference.

## Study sequence

Read [NOTES.md](NOTES.md) through optimization before watching videos I–IV.
Use videos V–VII to connect architecture ideas to the forward/backward
computation. Then run and inspect the
[NumPy network example](../examples/numpy_binary_mlp.py): derive one gradient by
hand, compare loss curves, and test the effect of weight decay and patience.
Finish the final recording and write a deployment checklist covering input
shape, preprocessing, evaluation, latency, numerical failure, and rollback.

See [the example guide](../examples/README.md) for execution instructions.
